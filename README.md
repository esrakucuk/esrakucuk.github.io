# Esra Nur Turan-Küçük: personal website

Static site (HTML + one CSS file). No build step.

Files: `index.html` (About), `publications.html`, `research.html`, `teaching.html`, `outreach.html`, `404.html`, `style.css`, `photo.jpg`, `cv.pdf`.

Preview locally: double-click `index.html`.

Deploy: GitHub repo `esrakucuk.github.io`, Settings > Pages > Deploy from branch `main` / root.
